# แผนที่กฎหมายอาญา — ประมวลกฎหมายอาญา

> ระดับ "แผนที่หมวดหมู่" เพื่อช่วยวางกรอบว่าสถานการณ์ของพี่ A เข้าข่ายความผิดหมวดไหน — ไม่ลง
> เลขมาตราละเอียดที่เสี่ยงผิด ถ้าต้องอ้างเลขมาตราเฉพาะ ให้ตรวจสอบกับแหล่งทางการก่อนเสมอ

## ภาค 1 — บทบัญญัติทั่วไป (สำคัญที่สุดสำหรับวิเคราะห์ทุกเคส)

```
โครงสร้างความรับผิดทางอาญา — เช็คทีละชั้นก่อนสรุปว่า "ผิดกฎหมายไหม":
  1. การกระทำเข้าองค์ประกอบความผิดตามที่กฎหมายบัญญัติไว้หรือไม่ (ไม่มีกฎหมาย ไม่มีความผิด)
  2. เจตนา (dolus) หรือประมาท (culpa) — ความผิดส่วนใหญ่ต้องมีเจตนา เว้นแต่กฎหมายระบุ
     ให้ลงโทษแม้ประมาทก็ได้ (เช่น ทำให้คนตายโดยประมาท)
  3. มีเหตุยกเว้นความผิดหรือไม่ (เช่น ป้องกันโดยชอบด้วยกฎหมาย, ความจำเป็น)
  4. มีเหตุยกเว้นโทษหรือลดโทษหรือไม่ (เช่น เด็กอายุต่ำกว่าเกณฑ์, วิกลจริต, บันดาลโทสะ)

รูปแบบการร่วมกระทำผิด: ตัวการ · ผู้ใช้ (ผู้บงการ) · ผู้สนับสนุน
ระดับความสำเร็จของการกระทำ: ความผิดสำเร็จ · พยายามกระทำความผิด (โทษเบากว่าสำเร็จ)

อายุความคดีอาญา: ผูกกับอัตราโทษของความผิดนั้นๆ (โทษยิ่งสูง อายุความยิ่งยาว)
  → ห้ามฟันธงจำนวนปีโดยไม่ตรวจสอบกับแหล่งทางการ ให้บอกหลักการนี้และแนะนำให้ตรวจสอบ
```

## ภาค 2 — ความผิด (หมวดที่พบบ่อยในชีวิตประจำวัน)

```
ความผิดเกี่ยวกับชีวิตและร่างกาย
  ฆ่าคนตาย (เจตนา/ไม่เจตนา/ประมาท) · ทำร้ายร่างกาย (บาดเจ็บสาหัส/ไม่สาหัส) · ทอดทิ้ง

ความผิดเกี่ยวกับเสรีภาพและชื่อเสียง
  หน่วงเหนี่ยวกักขัง · ข่มขืนใจ · หมิ่นประมาท (ใส่ความให้เสียชื่อเสียง ทั้งพูด/เขียน/โซเชียล)
  ดูหมิ่นซึ่งหน้า

ความผิดเกี่ยวกับทรัพย์ (พบบ่อยที่สุดในคดีที่ประชาชนทั่วไปเจอ)
  ลักทรัพย์ · วิ่งราวทรัพย์ · ชิงทรัพย์ · ปล้นทรัพย์ · กรรโชก · รีดเอาทรัพย์
  ฉ้อโกง (หลอกลวงให้ทรัพย์/เงิน — รวมแชร์ลูกโซ่, ฉ้อโกงออนไลน์)
  โกงเจ้าหนี้ · ยักยอกทรัพย์ (ครอบครองทรัพย์ผู้อื่นแล้วเบียดบังเอาเป็นของตน)
  รับของโจร · ทำให้เสียทรัพย์ · บุกรุก

ความผิดเกี่ยวกับเพศ
  ข่มขืนกระทำชำเรา · อนาจาร (รวมกรณีเกี่ยวกับผู้เยาว์ซึ่งมีเกณฑ์อายุพิเศษ)

ความผิดเกี่ยวกับความสงบสุขของประชาชน / ก่อให้เกิดภยันตรายต่อประชาชน
  บุกรุกเคหสถาน · วางเพลิง · ก่อให้เกิดอันตรายแก่ชีวิต/ทรัพย์สินของผู้อื่น

ความผิดเกี่ยวกับการปลอมและการแปลง
  ปลอมเอกสาร · ใช้เอกสารปลอม · ปลอมแปลงลายมือชื่อ

ภาค 3 — ลหุโทษ
  ความผิดเล็กน้อยโทษไม่หนัก (เช่น ทะเลาะวิวาทเล็กน้อย, ส่งเสียงดังรบกวน)
```

## จุดที่พี่ A ต้องระวังเป็นพิเศษ

```
- คดีอาญาแผ่นดิน vs คดีความผิดอันยอมความได้ (เช่น หมิ่นประมาท, ยักยอก) — ต่างกันตรงที่
  ผู้เสียหายถอนคำร้องทุกข์/ยอมความได้หรือไม่ ต้องระบุให้ชัดก่อนแนะนำขั้นตอน
- เหตุการณ์เดียวกันอาจมีทั้งประเด็นแพ่ง (เรียกค่าเสียหาย) และอาญา (ดำเนินคดี) พร้อมกันได้
  → ต้องวิเคราะห์แยก 2 ประเด็นเสมอ ไม่ปนกัน
- ผู้เสียหาย vs ผู้ถูกกล่าวหา มีสิทธิ/หน้าที่ต่างกันมาก ต้องถามให้ชัดว่าพี่ A อยู่ฝ่ายไหน
  ก่อนวิเคราะห์ (ดู "วิธีรับข้อมูลจากผู้ใช้" ใน SKILL.md หลัก)
```
