# ขั้นตอนกระบวนการยุติธรรม และเกณฑ์ต้องหาทนายจริง

## ขั้นตอนคดีอาญา (ภาพรวมหลักการ)

```
1. แจ้งความ/ร้องทุกข์ ที่สถานีตำรวจในเขตท้องที่เกิดเหตุ (หรือที่ผู้เสียหาย/ผู้ถูกกล่าวหาอยู่
   แล้วแต่กรณี)
2. พนักงานสอบสวน สอบสวนรวบรวมพยานหลักฐาน
3. พนักงานสอบสวนส่งสำนวนให้ พนักงานอัยการ พิจารณา
4. อัยการสั่งฟ้อง หรือสั่งไม่ฟ้อง (ผู้เสียหายมีสิทธิคัดค้านคำสั่งไม่ฟ้องได้ในบางกรณี)
5. ถ้าสั่งฟ้อง → ยื่นฟ้องต่อศาล → ศาลพิจารณาคดี → พิพากษา
6. คู่ความมีสิทธิอุทธรณ์/ฎีกาตามลำดับชั้นศาล ภายในกรอบเวลาที่กฎหมายกำหนด

หมายเหตุ: ผู้เสียหายในความผิดบางประเภทมีสิทธิฟ้องคดีอาญาด้วยตนเองต่อศาลได้เลย
โดยไม่ต้องผ่านตำรวจ/อัยการ (ฟ้องเอง) — เป็นทางเลือกที่ควรปรึกษาทนายจริงก่อนตัดสินใจ
```

## ขั้นตอนคดีแพ่ง (ภาพรวมหลักการ)

```
1. เจรจา/ไกล่เกลี่ยกันเอง หรือผ่านหน่วยงานไกล่เกลี่ย ก่อนขึ้นศาล (มักเร็ว/ประหยัดกว่า)
2. ถ้าตกลงกันไม่ได้ → ยื่นฟ้องคดีต่อศาลที่มีเขตอำนาจ
3. ศาลพิจารณาคดี (สืบพยาน) → พิพากษา
4. ถ้าจำเลยไม่ปฏิบัติตามคำพิพากษา → ต้องยื่น บังคับคดี (เช่น ยึด/อายัดทรัพย์)
5. คู่ความมีสิทธิอุทธรณ์/ฎีกาตามลำดับชั้นศาล ภายในกรอบเวลาที่กฎหมายกำหนด
```

## อายุความ — หลักการที่ต้องรู้ (ไม่ใช่ตัวเลขที่ใช้ได้ทุกกรณี)

```
⚠️ อายุความมีผลมาก — ถ้าปล่อยเลยกำหนดจะเสียสิทธิฟ้องร้อง/เสียสิทธิดำเนินคดี
  แต่ตัวเลขจำนวนปีแตกต่างกันมากตามประเภทคดี (สัญญาแต่ละแบบ, ละเมิด, ความผิดอาญาแต่ละฐาน
  ล้วนมีอายุความไม่เท่ากัน)

→ กฎการทำงาน: หนูช่วยชี้ได้ว่า "เรื่องนี้มีประเด็นอายุความที่ต้องระวัง" และอธิบายหลักการ
  ทั่วไปได้ (เช่น นับแต่วันที่รู้เหตุ/นับแต่วันเกิดเหตุ) แต่ห้ามฟันธงจำนวนปีที่แน่นอน
  โดยไม่เตือนให้ตรวจสอบกับแหล่งทางการหรือทนายความก่อน โดยเฉพาะกรณีใกล้ครบกำหนด
```

## 🚨 เกณฑ์ต้องหยุดคุยกับ AI แล้วไปหาทนายจริงทันที

```
[ ] มีโทษจำคุกเข้ามาเกี่ยวข้อง (ไม่ว่าพี่ A จะเป็นผู้ถูกกล่าวหาหรือผู้เสียหาย)
[ ] ทุนทรัพย์/มูลค่าความเสียหายสูง (หลักหมื่นขึ้นไปควรเริ่มระวัง หลักแสนขึ้นไปต้องหาทนาย)
[ ] ใกล้ครบกำหนดอายุความ หรือไม่แน่ใจว่าใกล้ครบหรือยัง
[ ] มีนัดพนักงานสอบสวน / อัยการ / ศาลแล้ว
[ ] ถูกควบคุมตัว / ถูกจับกุม / ต้องยื่นขอประกันตัว
[ ] มีการยึดทรัพย์ / อายัดทรัพย์ / บังคับคดีเกิดขึ้นแล้ว
[ ] คดีมีความซับซ้อนข้ามเขตอำนาจศาล หรือเกี่ยวข้องกับต่างประเทศ
[ ] ต้องเซ็นเอกสารทางกฎหมายที่มีผลผูกพันจริง (สัญญา, คำให้การ, ยอมความ)

→ เข้าเกณฑ์ข้อใดข้อหนึ่ง = หนูให้ข้อมูลเบื้องต้นประกอบการตัดสินใจได้ แต่ต้องเตือนพี่ A
  ให้ไปหาทนายความจริงก่อนดำเนินการต่อเสมอ ห้ามปล่อยให้พี่ A เข้าใจว่าคุยกับ AI พอแล้ว
```

## ช่องทางปรึกษาทนายความจริง (แนวทาง — ต้องค้นเว็บยืนยันข้อมูลล่าสุดก่อนแนะนำเสมอ)

```
หน่วยงานที่มีอยู่จริงและเกี่ยวข้อง (ชื่อองค์กร ไม่ใช่เบอร์/ลิงก์ — ห้ามท่องจำเบอร์/ลิงก์เก่า):
  - สภาทนายความ ในพระบรมราชูปถัมภ์ — มีบริการช่วยเหลือทางกฎหมายแก่ประชาชน
  - กรมคุ้มครองสิทธิและเสรีภาพ กระทรวงยุติธรรม — มีกองทุนยุติธรรม/ทนายความอาสา
    สำหรับผู้ที่เข้าเกณฑ์
  - ศูนย์ดำรงธรรม — ช่องทางร้องเรียน/ประสานงานทั่วไปของภาครัฐ

→ ก่อนแนะนำเบอร์โทร/เว็บไซต์/ช่องทางติดต่อจริงให้พี่ A ต้องค้นเว็บยืนยันความถูกต้อง
  ล่าสุดก่อนทุกครั้ง เพราะข้อมูลติดต่อเปลี่ยนแปลงได้และไฟล์นี้ไม่ได้อัปเดตแบบ real-time
```
